Privacy Policy

Effective October 24, 2026

This policy explains what data Ever Known? Studio (“the Studio”, “we”) accesses, stores and shares. The Studio is a private production tool operated by one independent creator to publish and manage videos on the creator's own YouTube channels, Ever Known? (@everknownq) and Ever Heard? (@everheardq). It is not offered to the public.

YouTube API Services

The Studio uses YouTube API Services (the YouTube Data API and the YouTube Analytics API). By using the Studio you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data we access

The channel owner signs in with Google (OAuth 2.0) and grants access to their own channels only. With that access the Studio reads and writes:

  • Channel details: channel ID, title, description, branding and public statistics (subscriber, view and video counts).
  • Our own videos: upload, titles, descriptions, tags, privacy status and publish time, thumbnails, caption tracks, playlists and translated metadata.
  • YouTube Analytics reports for our own channels: views, engaged views, watch time, average view percentage, subscribers gained and traffic sources.

The Studio does not access comments, messages, subscriber lists or any personal data of viewers or other YouTube users.

Data we store

  • Authorization tokens are stored on the operator's own computer in an access-restricted folder, for as long as the Studio is in use.
  • A registry of our uploads (video IDs, titles and file locations we created) is stored locally so the Studio knows what it has published.
  • Weekly analytics summaries for our own channels are stored locally for channel performance review. The Studio re-confirms its authorization every week when it requests new reports, and data about deleted videos is removed.
  • Statistics shown in the Studio's dashboard are fetched from YouTube when needed and cached in memory for a few minutes only.

Sharing

We do not sell, rent or share any data accessed through YouTube API Services with third parties, and we do not use it for advertising. Data is used only to run our own channels.

Cookies and device information

The Studio does not place cookies on or collect information from viewers' devices. This website is hosted on GitHub Pages; GitHub may log basic request data as described in the GitHub Privacy Statement.

Revoking access and deleting data

Access granted to the Studio can be revoked at any time through the Google security settings page at https://security.google.com/settings/security/permissions. To ask us to delete data the Studio has stored, email ttl2008@daum.net. We delete it within 7 days of a request, and within 30 days after access is revoked through Google's settings page.

Changes

If this policy changes, we will update this page and its effective date.
